# StudyOS — Учебная операционная система

**StudyOS** — это учебный проект, представляющий собой симулятор операционной системы, реализованный на Python 3.10+ с использованием встроенной базы данных SQLite. Проект разработан в рамках дисциплины «Осуществление интеграции программных модулей».

## Описание
Система имитирует работу реальной ОС на уровне абстракции пользователя. Вместо работы с физическим диском используется база данных SQLite, что позволяет легко отслеживать состояние системы и отлаживать ошибки.

## Возможности
-   **Управление пользователями:** Регистрация, вход (login/logout), разграничение прав (роли: admin, user, guest).
-   **Иерархическая файловая система:** Создание файлов и каталогов, навигация (`cd`, `pwd`), копирование, перемещение, удаление, построение дерева (`tree`).
-   **Управление процессами:** Создание процессов (`run`), планирование (Round Robin), завершение (`kill`), мониторинг (`ps`).
-   **Управление памятью:** Выделение памяти при создании процесса, контроль лимита (1024 МБ), освобождение при завершении.
-   **Журналирование:** Все системные вызовы записываются в таблицу `syscalls_log` с указанием статуса (OK, DENIED, EXISTS).

## Стек технологий
-   **Язык:** Python 3.10+
-   **База данных:** SQLite (встроенная библиотека `sqlite3`)
-   **Контроль версий:** Git
-   **Среда:** VS Code
