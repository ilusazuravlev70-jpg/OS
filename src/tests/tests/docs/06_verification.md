# Верификация нефункциональных требований (NFR)

| ID | Требование | Метод проверки | Фактический результат | Статус |
|---|---|---|---|---|
| NFR-1 | Время syscall ≤ 50 мс | Замер через time.perf_counter() в тесте | Среднее время 12 мс | Выполнено |
| NFR-2 | Стабильность при 10 процессах | Тест создает 10 процессов в цикле | Система стабильна, OOM не возник | Выполнено |
| NFR-3 | Ошибка процесса не роняет ядро | Запуск процесса с ошибкой (пустое имя) | Ядро работает, ошибка в логе | Выполнено |
| NFR-4 | Пароли в виде хэша SHA-256 | Проверка таблицы users через SQLite Viewer | Поле password_hash = 64 hex-символа | Выполнено |
| NFR-5 | User не удаляет файл Admin | Вызов sys_delete_file от user для файла admin | Возврат False, файл на месте | Выполнено |
| NFR-6 | Модули ≤ 300 строк | Команда `wc -l src/*.py` | Максимум 285 строк (shell.py) | Выполнено |
| NFR-7 | Логирование всех syscalls | Проверка таблицы syscalls_log | Записи для create, read, exec, kill | Выполнено |
| NFR-8 | Без внешних СУБД | Проверка импортов (grep -r "^import") | Только sqlite3 и stdlib | Выполнено |
