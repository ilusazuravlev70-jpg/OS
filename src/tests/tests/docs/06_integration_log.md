## Найденные и исправленные ошибки

### Ошибка 1: sys_delete_file не проверял владельца
* **Симптом:** Тест `test_permission_isolation` падал, user удалял файл admin.
* **Причина:** В функции `sys_delete_file` не запрашивался владелец файла перед проверкой прав.
* **Исправление:** Добавлен вызов `owner = fs.get_owner(path)` и передача его в `check_permission`.
* **Дата исправления:** 06.10.2026

### Ошибка 2: Прямой импорт sqlite3 в fs.py
* **Симптом:** Нарушение архитектуры (NFR-8).
* **Причина:** В модуле `fs.py` остался старый код подключения.
* **Исправление:** Все вызовы `sqlite3.connect` удалены, используется только `db.py`.
