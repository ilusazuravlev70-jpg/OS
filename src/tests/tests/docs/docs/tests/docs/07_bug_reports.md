# Баг-репорты (День 7)

## BUG-01: Попытка создать дубликат файла
**Серьёзность:** Средняя
**Приоритет:** Средний
**Статус:** Закрыт (не воспроизводится / работает как задумано)
**Шаги воспроизведения:**
1. Вызвать sys_create_file('/dup.txt', 'a', 'admin').
2. Повторно вызвать sys_create_file('/dup.txt', 'b', 'admin').
**Ожидаемый результат:** Второй вызов возвращает -1.
**Фактический результат:** Второй вызов возвращает -1.
**Причина:** В fs.create_file выполняется проверка на существование через execute_select.
**Решение:** Дефект не обнаружен, поведение корректное.

## BUG-02: (Пример, если бы упал тест) Падение при смене пароля
**Серьёзность:** Высокая
**Приоритет:** Высокий
**Статус:** Открыт
**Шаги воспроизведения:**
1. Вызвать change_password('admin', 'new').
**Ожидаемый результат:** True.
**Фактический результат:** Exception: no such table: users.
**Причина:** init_db не вызывается перед тестом.
**Решение:** Добавить вызов init_db в setup фикстуру тестов.
