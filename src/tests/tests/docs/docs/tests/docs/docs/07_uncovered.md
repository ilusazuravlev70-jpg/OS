# Непокрытые функции

## db.py
*   init_db() — вызывается косвенно при запуске, отдельного теста нет.
*   get_connection() — используется всеми функциями, отдельного теста нет.

## kernel.py
*   memory_info() — покрыт косвенно.
*   save_memory_state() — **не покрыт** (требуется отдельный тест).
*   load_memory_state() — **не покрыт** (требуется отдельный тест).

## auth.py
*   Все функции покрыты.
