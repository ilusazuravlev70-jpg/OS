# Тест-кейсы (День 7)

## Модуль db.py

**TC-01: execute_select возвращает данные**
*   **Шаги:** Вызвать execute_select("SELECT 1 as val", ()).
*   **Ожидаемый результат:** Список [{'val': 1}].
*   **Статус:** Пройден.

**TC-02: execute_insert возвращает ID**
*   **Шаги:** Вызвать execute_insert на тестовую таблицу.
*   **Ожидаемый результат:** Целое число > 0.
*   **Статус:** Пройден.

**TC-03: Обработка пустой выборки**
*   **Шаги:** Вызвать execute_select("SELECT * FROM non_existing", ()).
*   **Ожидаемый результат:** Пустой список [].
*   **Статус:** Пройден.

## Модуль kernel.py

**TC-04: Выделение памяти (успешно)**
*   **Шаги:** kernel.allocate_memory(100).
*   **Ожидаемый результат:** True, memory_used = 100.
*   **Статус:** Пройден.

**TC-05: Выделение памяти (превышение лимита)**
*   **Шаги:** kernel.allocate_memory(2000).
*   **Ожидаемый результат:** False.
*   **Статус:** Пройден.

**TC-06: Сохранение состояния памяти**
*   **Шаги:** kernel.allocate_memory(50) -> kernel.save_memory_state().
*   **Ожидаемый результат:** В БД memory_state поле used = 50.
*   **Статус:** Пройден.

## Модуль auth.py

**TC-07: Хэширование пароля**
*   **Шаги:** hash_password("secret").
*   **Ожидаемый результат:** Строка длиной 64 символа, не равная "secret".
*   **Статус:** Пройден.

**TC-08: Проверка валидных учетных данных**
*   **Шаги:** check_credentials("admin", "secret").
*   **Ожидаемый результат:** True.
*   **Статус:** Пройден.

**TC-09: Проверка невалидных учетных данных**
*   **Шаги:** check_credentials("admin", "wrong").
*   **Ожидаемый результат:** False.
*   **Статус:** Пройден.

**TC-10: Регистрация нового пользователя**
*   **Шаги:** register_user("newuser", "12345").
*   **Ожидаемый результат:** True, запись в таблице users.
*   **Статус:** Пройден.
