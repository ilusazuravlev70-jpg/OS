# Тест-план учебной операционной системы (StudyOS)

## 1. Введение
**Цель:** Проверка работоспособности модулей учебной ОС перед финальной интеграцией.
**Область применения:** Модули db.py, kernel.py, auth.py, fs.py, scheduler.py, syscalls.py.
**Исключения:** Командная оболочка (shell.py) тестируется в рамках интеграционных сценариев, а не модульно.

## 2. Объём тестирования
**Входит в тестирование:**
*   Функции работы с базой данных (CRUD).
*   Управление памятью и PID в ядре.
*   Хэширование паролей, аутентификация и разграничение прав.
*   Файловая система (создание, чтение, удаление).
*   Планировщик процессов (создание, очередь, завершение).

## 3. Виды тестирования
*   **Модульное (Unit):** Проверка каждой функции в изоляции (основной вид для этого дня).
*   **Регрессионное:** Повторный запуск всех тестов после внесения изменений.
*   **Негативное:** Проверка реакции системы на невалидные данные (пустые строки, дубликаты).

## 4. Ресурсы
*   **Инструменты:** VS Code, Python 3.10+, SQLite.
*   **Среда:** Локальный запуск на Windows/Linux/macOS.

## 5. Расписание
*   День 7: Написание тест-плана, тест-кейсов, модульных тестов для db, kernel, auth.
*   День 8: Интеграционное тестирование и проверка оболочки.

## 6. Критерии начала и окончания
*   **Начало:** Наличие реализованных модулей (src/*) и базы данных.
*   **Окончание:** Все модульные тесты (test_db.py, test_kernel_unit.py, test_auth_unit.py) проходят (статус [PASS]).
