# Баг-репорты (День 8)

## BUG-08-01: Отказ в правах не логируется как DENIED
**Серьёзность:** Средняя
**Приоритет:** Средний
**Статус:** Закрыт (исправлено)
**Сценарий:** IS-03
**Шаги:** 1. user пытается удалить файл admin. 2. Проверка таблицы syscalls_log.
**Ожидаемый результат:** Статус DENIED.
**Фактический результат:** Запись отсутствовала.
**Причина:** В sys_delete_file не было вызова log_syscall в ветке отказа.
**Решение:** Добавлен вызов log_syscall('sys_delete_file', user, 'DENIED').

**Серьёзность:** Высокая
**Приоритет:** Высокий
**Статус:** Закрыт (не воспроизводится)
**Шаги:** 1. Запомнить kernel_instance.memory_used. 2. sys_exec. 3. Сравнить.
**Фактический результат:** Память увеличивается корректно.
