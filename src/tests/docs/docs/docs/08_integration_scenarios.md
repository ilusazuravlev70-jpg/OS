# Интеграционные сценарии (День 8)

## IS-01: Создание файла через оболочку
**Участники:** user, shell, syscalls, fs, db.
**Предусловие:** Пользователь admin авторизован.
**Шаги:** Пользователь вводит `create /is01.txt content`.
**Ожидаемый результат:** Файл создан, запись в syscalls_log со статусом OK.

## IS-02: Чтение файла через оболочку
**Участники:** user, shell, syscalls, fs, db.
**Предусловие:** Файл /is02.txt существует.
**Шаги:** Пользователь вводит `cat /is02.txt`.
**Ожидаемый результат:** Выведено содержимое файла.

## IS-03: Удаление чужого файла
**Участники:** user, shell, syscalls, auth, fs, db.
**Предусловие:** Файл /is03.txt принадлежит admin, текущий пользователь — user.
**Шаги:** Пользователь вводит `delete /is03.txt`.
**Ожидаемый результат:** Отказ, запись в syscalls_log со статусом DENIED.

## IS-04: Запуск процесса
**Участники:** user, shell, syscalls, kernel, scheduler, db.
**Предусловие:** Памяти достаточно.
**Шаги:** Пользователь вводит `run is04_app`.
**Ожидаемый результат:** Процесс создан, память выделена, запись в syscalls_log со статусом OK.

## IS-05: Завершение процесса
**Участники:** user, shell, syscalls, scheduler, kernel, db.
**Предусловие:** Процесс с PID существует.
**Шаги:** Пользователь вводит `kill PID`.
**Ожидаемый результат:** Процесс завершён, память освобождена.

## IS-06: Сквозной сценарий администратора
**Участники:** user, shell, syscalls, kernel, auth, fs, scheduler, db.
**Предусловие:** Система в исходном состоянии.
**Шаги:** login → create файл → cat файл → run процесс → ps → kill → mem → exit.
**Ожидаемый результат:** Все шаги выполнены, журнал заполнен.

## IS-07: Сквозной сценарий обычного пользователя
**Участники:** user, shell, syscalls, kernel, auth, fs, db.
**Предусловие:** Пользователь user зарегистрирован.
**Шаги:** login → create свой файл → попытка удалить чужой → run → kill чужой процесс → exit.
**Ожидаемый результат:** Свои действия разрешены, чужие запрещены, отказы в журнале.
