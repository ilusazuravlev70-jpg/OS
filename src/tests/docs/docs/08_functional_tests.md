# Функциональные тесты модулей (День 8)

## Модуль fs.py (Файловая система)
*   **FT-FS-01:** Создание файла. Проверка возврата ID и наличия записи в БД.
*   **FT-FS-02:** Чтение существующего файла. Проверка возврата корректного содержимого.
*   **FT-FS-03:** Чтение отсутствующего файла. Проверка возврата пустой строки.
*   **FT-FS-04:** Запись в файл. Проверка обновления содержимого.
*   **FT-FS-05:** Удаление файла. Проверка возврата True и исчезновения из БД.
*   **FT-FS-06:** Дубликат файла. Проверка возврата -1.
*   **FT-FS-07:** Список файлов. Проверка фильтрации по префиксу.
*   **FT-FS-08:** Владелец файла. Проверка возврата корректного логина.

## Модуль scheduler.py (Планировщик)
*   **FT-SCH-01:** Создание процесса. Проверка возврата PID и статуса 'ready'.
*   **FT-SCH-02:** Нехватка памяти. Проверка возврата -1 при лимите.
*   **FT-SCH-03:** Завершение процесса. Проверка освобождения памяти.
*   **FT-SCH-04:** Список процессов. Проверка возврата всех активных PID.
*   **FT-SCH-05:** Round Robin. Проверка смены состояния 'ready' -> 'running'.

## Модуль syscalls.py (Системные вызовы)
*   **FT-SYS-01:** sys_create_file (OK). Проверка создания и лога.
*   **FT-SYS-02:** sys_create_file (DENIED). Проверка прав пользователя.
*   **FT-SYS-03:** sys_read_file (OK).
*   **FT-SYS-04:** sys_delete_file (DENIED). Попытка удалить чужой файл.
*   **FT-SYS-05:** sys_exec (OK). Проверка выделения памяти.
*   **FT-SYS-06:** sys_kill (OK). Проверка завершения и лога.
*   **FT-SYS-07:** sys_ps. Проверка вывода списка.
*   **FT-SYS-08:** Полнота журнала. Проверка наличия статусов check, OK, DENIED.
