# Отчёт о разработке за дни 4–6

## Что сделано
За три дня раздела «Разработка, отладка и интеграция модулей» реализовано девять модулей операционной системы: db.py, kernel.py, auth.py, fs.py, scheduler.py, logger.py, syscalls.py, shell.py, config.py.
Реализованы все системные вызовы: sys_login, sys_logout, sys_whoami, sys_create_file, sys_read_file, sys_delete_file, sys_list_files, sys_exec, sys_ps, sys_kill, sys_mem_alloc, sys_logs, sys_shutdown.
Написано шесть файлов тестов: test_kernel.py, test_auth.py, test_permissions.py, test_fs.py, test_scheduler.py, test_integration.py.
Пройдена верификация по восьми нефункциональным требованиям из матрицы трассируемости.

## Обнаруженные и исправленные ошибки

### Ошибка 1: sys_delete_file не проверял владельца
* **Симптом:** user мог удалить файл admin.
* **Причина:** в check_permission не передавался владелец файла.
* **Исправление:** добавлен вызов fs.get_owner перед проверкой.

### Ошибка 2: модуль syscalls.py превысил 300 строк
* **Симптом:** сложно ориентироваться в коде.
* **Причина:** все вызовы и логирование в одном файле.
* **Исправление:** вынесена функция log_syscall в logger.py.
